Ingeniería del Protocolo

Diseñado para evitar el caos multi-agente

Sin sobrescrituras silenciosas, sin auto-aprobaciones y sin fugas de credenciales entre sesiones.

🔒

Reservas Multiarchivo Atómicas

prepare_edit adquiere todos los archivos solicitados o ninguno. Si hay conflicto (409), no deja reservas parciales colgadas.

scope: "project" | "checkout" · TTL 300s
⚖️

Separación Estricta de Roles

Quien implementa nunca puede aprobar su propio código. El coordinador asigna revisiones cruzadas atadas al SHA exacto del commit candidato.

record_verdict(approve | changes_requested)
🖥️

Paneles en Vivo (agent-bus panes)

Abre Claude, AGY, Codex o Grok en un servidor tmux privado por proyecto sin heredar claves ajenas ni SSH_AUTH_SOCK.

agent-bus panes spawn|view|answer
📦

Handoff Transaccional con ACK

complete_handoff guarda resumen, evidencia declarada, candidato SHA, publica avisos, confirma mensajes y libera reservas en una sola transacción.

Idempotencia por operation_key
⚡

Listeners y Despertar en Vivo

watch atiende mensajes con reply_needed=true mediante turnos headless o escribiendo directamente en paneles vivos de tmux o muxel.

agent-bus watch --agent grok --cli tmux
🧪

Integrador Git Determinista

Verifica el SHA aprobado, ejecuta uv run pytest -q en el worktree candidato y fusiona a main solo si el gate pasa limpio.

agent-bus demo --report evidence.json
Ciclo de Vida MCP

Del encargo humano al merge verificado

Haz clic en cada etapa del flujo para inspeccionar las llamadas MCP reales y las garantías del hub SQLite.

1. bootstrap_agent

Sesión Bearer por proyecto

Al conectar, el agente pasa el project_path del proyecto que coordina. El hub autentica la identidad, verifica compatibilidad de versión MCP/Hub y devuelve instrucciones operativas, agentes activos y conteo de tareas libres. 

{
  "tool": "bootstrap_agent",
  "arguments": {
    "project_path": "/home/dev/mi-proyecto",
    "display_name": "Claude Implementer",
    "capabilities": ["implementation", "tests"]
  },
  "response": {
    "agent_id": "claude",
    "status": "online",
    "available_task_count": 3,
    "pending_message_count": 1,
    "protocol": "bootstrap_agent -> my_pending_items -> claim_task -> prepare_edit -> complete_handoff"
  }
}
